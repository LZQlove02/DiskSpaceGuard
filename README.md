# DiskSpaceGuard — M9 发布

Windows 10/11 · WPF · .NET 8。当前阶段：只读扫描 + 三视图 + 文件用途查询 + **默认回收站的显式清理（文件与目录递归）** + **硬件信息页** + **重复文件检测** + **应用管理（仅调用官方卸载入口）** + **单文件发布 / Inno Setup 安装包 / 诊断导出**。

## 功能总览（截至 M9）
- 五级保护：`L0` 硬禁止（`%SystemRoot%`/System32、卷根、pagefile/hiberfil/swapfile、`$Recycle.Bin`、SVI、程序自身目录）/ `L1` 重解析点不穿透 / `L2` 强确认（Program Files、用户目录、AppData）/ `L3` 常规 / `L4` 自定义保护
- **删除计划不可变**：`DeletePlan` + `DeleteItem` 为不可变记录，`PlanHash`（SHA-256，含 schema/plan 版本）覆盖路径、大小、时间戳、卷序列号、FileId、保护级别；执行前先校验版本再重算哈希，任一不符直接拒绝
- **执行前对象校验**：永久删除用 `CreateFileW(DELETE)` → `FileIdInfo` → `SetFileInformationByHandle(FileDispositionInfoEx + POSIX_SEMANTICS)`，校验身份与大小后才删除；不一致、身份不可读一律跳过
- **回收站优先**：默认移入回收站；回收站失败只报失败，**绝不静默降级为永久删除**
- 对象变化、缺失、无权限分别归类，不中断整体队列
- 同一 `PlanId` 二次提交被拒绝；执行结果写入 `%LOCALAPPDATA%\DiskSpaceGuard\cleanup-log.jsonl`
- **目录递归清理（T18）**：选中已扫描目录后按磁盘现状展开计划，自底向上逐个删除；不使用 `Directory.Delete(recursive:true)`。执行时新增的计划外项一律不删，目录因此非空则如实保留；重解析点不穿透
- **清理规则引擎（§14.2）**：内置具名规则（用户临时文件、Chrome/Edge 缓存、系统网络缓存、崩溃转储），每条建议带稳定 `RuleId`、命中/排除统计与保护级别；只统计不勾选，执行仍走预演与确认
- **清理台账界面**：顶栏「清理台账」查看每次执行的计划哈希、成功/跳过/失败统计与逐项明细；损坏行自动跳过并计数，支持导出 CSV 与**从回收站还原本次记录**
- **托盘与主题（M5）**：关闭窗口默认最小化到托盘（设置可关）；托盘菜单支持打开主窗口与退出；启动时按 `AppsUseLightTheme` 跟随系统浅色/深色
- **中英双语（M5）**：设置页切换 中文 / English，界面即时更新，无需重启；系统原生窗口菜单与按钮仍随 Windows 语言
- **硬件信息（M6）**：存储 WMI 枚举物理盘（型号、序列号、固件、总线、介质、健康、分区/盘符）；SMART 字段按设备能力分层读取，拿不到统一显示“不可用”并说明原因；寿命消耗原样展示（可能 >100%），不推算剩余寿命
- **重复文件（M7）**：大小分组 → 采样哈希筛除 → SHA-256 全量哈希；硬链接、0 字节、云占位、L0/L4 保护路径排除；默认不勾选，推荐保留仅为低置信度建议；删除前重新计算 SHA-256 并复核身份/时间戳；**拒绝把组内所有副本一起清理**
- **应用管理（M8）**：注册表 64/32 位视图 + 当前用户 + MSIX 枚举；MSI 按 ProductCode、MSIX 按 PackageFamilyName、其他按名称/发布者/版本哈希去重；系统组件、补丁、父项、框架包与空名称默认隐藏（设置可开）；**只调用应用自带的官方卸载入口**（含 `MsiExec /X{ProductCode}` 与 `Remove-AppxPackage`），确认弹窗显示确切命令行，静默模式二次确认，拒绝提权不降级；卸载后重新枚举并如实报告；独立 `app-ops.jsonl` 台账；卸载残留仅登记为 `app.leftovers` 候选，**不自动删除**
- **诊断导出（M9）**：硬件页「导出诊断报告…」；导出前完整预览，默认把用户名与用户目录替换为 `<user>`；ZIP 含系统/.NET/OS、卷与 GUID、设置快照、硬件能力矩阵、清理与应用台账尾部、运行日志尾部（各 200 行）与最近异常；**不包含任何文件内容**
- **运行日志（M9）**：`run.log` 记录异常摘要并默认脱敏，超过 1 MB 轮转；`last-error.txt` 保留最近一次异常；WPF/AppDomain/未观察 Task 异常均落盘
- **空间复核**：执行前后各读一次所在卷 `TotalFreeSpace`，结果页显示“前 → 后（Δ 已释放/未释放）”；回收站模式空间可能延迟释放
- **L4 设置界面**：顶栏「设置」→ 管理自定义保护目录，保存到 `%LOCALAPPDATA%\DiskSpaceGuard\settings.json`，重启后自动加载
- 界面：列表多选 →「清理所选…」→ 预演弹窗（条目/预计释放/强确认数/禁止数/计划哈希/方式）→ 确认 → 结果汇总

## 本包包含
- 五个主导航页面：总览、空间分析、重复文件、应用管理、硬件信息
- 按当前用户 SID 与 Windows Session 隔离的 Mutex 单实例
- 命名管道激活已有窗口；服务端限制为当前用户，命令读取有长度上限
- `DriveInfo` 容量卡片：总量、已用、卷可用、当前用户可用、使用率、文件系统与卷类型；配额差异会单独提示
- 手动刷新与 `WM_DEVICECHANGE` 插拔设备防抖刷新
- **扫描内核**：
  - 三种模式：完全递归 / 分层（深度 1–3）/ 先快后全
  - 显式状态机（Idle → Preparing → Running → Pausing/Paused → Cancelling → 终态），按钮可用性由状态驱动
  - 暂停 / 继续 / 取消；取消后保留已扫描的部分结果
  - 按目录隔离异常，分类统计：无权限 / 不存在 / 共享冲突 / 路径过长 / 设备断开 / 其他 IO
  - 目录重解析点默认不跟随，单独计数；不进入 junction / symlink 目标
  - 分层边界上的目录标记“未扫描”，大小显示 `—`，不伪装成 0
  - **内存剪枝**：< 1 MB 的文件按目录合并为「其他 N 个文件」，父目录大小仍为全量
- **M3 可视化**：
  - 树图：文件级嵌套，目录块内继续绘制子层，直到文件叶子；**黄金分割二分布局**（目标切点 61.8%，每块面积仍与文件大小严格正比；可能产生超过 φ² 长宽比时退让到最优切点）；单次最多 1500 块，超出部分折叠并提示
  - 树图层级：目录标题条压暗作为区块锚点，子项按层级逐层提亮；叶块使用 1px 浅色分隔线（小于 12px 的块不描边）
  - 树图文字按底色相对亮度自动取黑/白，保证正文 ≥4.5:1；悬停块显示描边（悬停层独立，不触发整图重排）
  - 旭日图：最多 3 层；条形图：按高度自适应行数（上限 20），其余折叠为汇总行
  - 三种配色：按类型（系统/程序/影音/文档/压缩包/其他）、按层级、按大小
  - 点击目录下钻，点击文件打开说明；“上一级”返回；表格与图表同源
  - 树图在本层 > 400 项时自动降级为条形图并提示原因
- **文件用途查询**：离线扩展名说明 + 保护判定（L0 / 建议保留 / 先确认 / 通常可清理 / 个人文件 / 未知）+ 只发送文件名的 Bing / 百度搜索；合并项禁用搜索
- **发布产物（M9）**：`win-x64` self-contained 单文件 `DiskSpaceGuard.exe`（无需目标机安装 .NET 8）+ Inno Setup 安装包；构建脚本 `installer/build-release.ps1`
- 真实执行入口只有「清理所选」与「卸载」：前者必须经过预演与显式确认；后者只启动应用自带的官方卸载程序，绝不删除安装目录或注册表项

## 构建与运行
需要 Windows 10/11 与 .NET 8 SDK。用 Visual Studio 2022 打开 `DiskSpaceGuard.sln`，或在根目录运行：

```powershell
dotnet build DiskSpaceGuard.sln
dotnet run --project src/DiskSpaceGuard/DiskSpaceGuard.csproj
```

发布单文件与安装包（需要 .NET 8 SDK 与 Inno Setup 6/7）：

```powershell
powershell -ExecutionPolicy Bypass -File installer\build-release.ps1 -Version 1.0.0
```

产物位于 `dist\publish\DiskSpaceGuard.exe` 与 `dist\DiskSpaceGuard-Setup-1.0.0.exe`。若只想要单文件 exe，加 `-SkipInstaller`。

## M4 验收清单
1. 选中 `pagefile.sys` 等 L0 文件 → 预演显示禁止 1 项、可删除 0 项，“执行”按钮置灰。
2. 选中普通文件（临时目录）→ 预演列出路径/大小/保护级别，并显示计划哈希。
3. 默认方式为回收站；切换永久删除后提示“不可恢复”。
4. L2 目录（Program Files、用户目录）需输入目标文件夹名才能执行，输入不匹配则拒绝；跨多个不同父目录时需用逗号分隔逐一输入全部目录名。
5. 预演后修改文件（大小变化）→ 执行时跳过，文件保留。
6. 篡改计划字段 → 执行被拒绝并提示哈希不一致；把 `PlanVersion` 改为不兼容值 → 提示版本不兼容并拒绝。
7. 同一计划重复执行 → 第二次被拒绝。
8. 回收站操作失败（网络盘/配额）→ 报告失败，文件保留，不改为永久删除。
9. 无法读取对象身份的文件 → 执行时跳过并在预演中提示“无法读取对象身份”。
10. 用同尺寸新文件替换并复位时间戳 → 执行仍跳过（身份不同）。
11. 清理结果写入 `cleanup-log.jsonl`，可用文本编辑器查看；异常退出留下的半行会在下次启动时截断。
12. 实测清理若干文件 → 结果页显示“空间复核：前 → 后（Δ …）”；回收站模式 Δ 可能为 0 或滞后。
13. 顶栏「设置」→ 添加一个目录并保存 → 关闭后重新打开设置仍在；重启应用后仍在；该目录下文件在计划中为 L4。
14. 选中一个已扫描目录 → 预演显示“文件 N / 目录 M”，执行后目录树按自底向上被移除。
15. 预演后在目标目录内新建文件 → 执行时该文件保留，目录保留，结果提示“计划外项 N 个”。
16. 目标目录内含 junction → 预演提示未穿透数量；执行后 junction 与目标内容均保留。
17. 空间分析 →「清理建议…」→ 列出具名规则命中项与排除数；选中后「预演清理所选」必须经过预演与确认，不会直接删除。
18. 顶栏「清理台账」→ 列表显示历史执行记录；选中后右侧显示计划哈希与逐项结果；损坏行会被跳过并在状态栏计数；「导出 CSV…」可用 Excel 打开中文不乱码。
19. 设置 → 取消/勾选「关闭窗口时最小化到托盘」→ 点窗口 X 后窗口消失但进程仍在托盘；再次启动应用应唤回同一窗口。
20. 设置 →「跟随系统深色主题」在下次启动生效（深色系统下窗口与卡片切换为深色）。
21. 设置 → 界面语言切到 English → 主窗口、设置、预演、规则、台账即时变英文；切回中文同样即时。
22. 台账选中一条回收站记录 →「还原本次记录…」→ 确认后对象回到原路径；已清空的回收站对象会如实报告“未找到”。
23. 硬件信息页 → 列出物理盘与分区/盘符；总线、介质、健康状态与 WMI 一致；SMART 不可用时显示原因，不填 0、不推算剩余寿命。
24. 硬件页「刷新硬件」可重新读取；切换到 English 后硬件页字段同步变英文。
25. 重复文件页选择卷或文件夹 →「开始查重」→ 只把大小与内容完全相同的文件归为一组；硬链接/0 字节/系统受保护路径不参与。
26. 采样相同但内容不同的文件不得判重；勾选副本后「清理所选…」必须先通过 SHA-256 复核才能进入预演。
27. 勾选组内全部副本 → 提示“至少保留一个副本”并拒绝生成计划；不稳定副本的复选框不可用。
28. 应用管理页 → 列出桌面与 Microsoft Store 应用；名称/发布者/版本/安装日期/占用（估算）/来源/卸载入口状态完整；搜索、来源筛选、排序与“仅显示可卸载”生效。
29. 默认不显示系统组件、补丁、父产品子项与框架包；设置 →「在应用管理中显示系统组件与补丁条目」打开后可显示，但硬禁止项仍无卸载入口。
30. 点任意可卸载条目的「卸载」→ 确认弹窗必须显示**将执行的确切命令行**与“不会删除安装目录或注册表项”说明；取消后不得启动任何程序。
31. 静默复选框只在应用提供 QuietUninstallString 时出现；勾选后执行前还会再确认一次。
32. 需要管理员的条目（HKLM / MSI）执行时请求提权；拒绝后提示未执行，不得改为非提权执行。
33. 卸载程序退出后重新检测：退出码非 0 或仍存在时提示“卸载未完成”；`%LOCALAPPDATA%\DiskSpaceGuard\app-ops.jsonl` 有对应记录；残留目录只出现在清理建议 `app.leftovers` 中，不会自动删除。
34. 硬件页 →「导出诊断报告…」→ 窗口显示预览与将包含的文件；默认勾选脱敏，预览中用户名与 `C:\Users\...` 显示为 `<user>`。
35. 取消勾选脱敏 → 预览刷新并明确显示“脱敏：关闭”；重新勾选恢复。
36. 导出 ZIP → 内含 README、system、settings、hardware、cleanup/app-ops/run-log 尾部；日志各不超过 200 行；不含任何文件内容。
37. 双击 `dist\publish\DiskSpaceGuard.exe` 在未安装 .NET 8 的环境也能启动（self-contained 单文件）。
38. 运行 `installer\build-release.ps1` → 生成单文件 exe 与 `DiskSpaceGuard-Setup-1.0.0.exe`；安装器包含管理员权限、开始菜单/桌面快捷方式与卸载入口；`dist\SHA256SUMS.txt` 由脚本自动生成。
39. 确认执行后弹窗显示进度条与“已处理 X / Y 项”实时计数（含跳过项）；点「停止」随时中断，已完成的操作不回滚，结果页如实显示“已取消”与部分结果；执行中关闭窗口被拦截并提示先停止或等待。

1. 扫描完成后树图按目录内嵌绘制到文件层；目录有标题条，文件块显示名称与大小。

- 树图单层最多 1499 块 + 1 个「其余 N 项」；嵌套层达到 1500 预算后截断并提示，深层小块只保留面积。

## M4 已知限制
- **递归计划按生成时的磁盘现状展开**：超过 50,000 项时拒绝生成；扫描树里被合并的小文件不影响计划，因为计划会重新枚举磁盘。
- 目录内含重解析点或无法读取的子目录时，这些对象不入计划，上级目录通常无法删净而保留；预演会提示数量。
- 回收站模式按项移入回收站：递归清理会产生多条回收站记录，而不是把顶层目录作为一个整体移入。
- 规则引擎内置规则固定且只读（尚未提供启用/禁用与自定义规则）；规则只统计不自动勾选，合并项不可直接勾选。
- 回收站只能按路径操作：先校验身份再交给 Shell，仍存在窄竞态窗口；文档不宣称消除 TOCTOU。
- 空间复核只读卷级 `TotalFreeSpace`，多计划同时落盘或系统后台写入会干扰 Δ；回收站模式空间延迟释放，Δ 可能为 0。
- 计划哈希只用于**完整性校验**（防误改），不是鉴权：能改文件的人也能重算哈希。
- L4 保护目录通过顶栏「设置」管理；`settings.json` 损坏时回退为空列表（不会误放宽内置 L0–L2 规则）。
- 台账为 JSONL，已有只读查看、CSV 导出与回收站还原；还原结果目前只显示在结果弹窗，不写回台账。崩溃留下的半行会在下次启动时自动截断。
- 主题只支持启动时跟随系统/浅色，运行中切换系统主题需重启。
- 中英双语覆盖应用自绘界面；Windows 原生标题栏菜单/按钮随系统语言，不受应用切换控制。
- 硬件 SMART 依赖存储 WMI 与权限：普通权限下通常只能读到磁盘基础信息；SMART 字段缺失时统一显示“不可用”，不填充默认值。
- 硬件页不显示“剩余寿命百分比”，只展示设备报告的寿命消耗；不据此推算剩余年限。
- 重复文件一次只扫描一个卷或文件夹，不自动合并跨卷结果；全量哈希使用 SHA-256（未实现 xxHash64 快速模式）。
- 重复文件的“建议保留”只是路径长度/用户目录启发式，低置信度，不代表文件更重要；默认不勾选任何副本。
- 大卷查重需要遍历并哈希候选文件，耗时随文件数增长；未实现哈希缓存或增量索引。

## M8 已知限制
- 本轮未实际执行任何第三方卸载程序，只验证到确认弹窗取消；T32 的“真实卸载 + 退出码/取消”集成场景待补。
- MSIX 卸载使用官方 cmdlet `Remove-AppxPackage`，未直接引用 WinRT `PackageManager.RemovePackage`；属于同一系统 API 路径。
- Store 应用显示名使用包 `Name`，未解析 manifest 本地化 DisplayName，部分条目显示包标识而非友好名称。
- 卸载后残留只在“重新检测确认已移除且安装目录存在”时登记；共享根目录、Windows、Program Files、ProgramData、AppData 与用户目录不会被登记。`app.leftovers` 只作清理候选，仍需预演与确认。
- 应用台账只写入 `%LOCALAPPDATA%\DiskSpaceGuard\app-ops.jsonl`，暂无独立查看界面。
- 卸载等待上限 10 分钟；超时只提示“仍在运行”，不会终止卸载程序。

## M9 审查修复（2026-10-21 第二轮）
1. 执行进度与可取消：计划弹窗接入逐项进度（含跳过项计数）与「停止」按钮，执行中拦截窗口关闭；`DeleteService` 所有分支统一上报 `IProgress`，原先仅删除尝试上报导致跳过项不计数。
2. `FileIdInfo` 结构体布局修正：旧定义 8+8+8=24 字节与原生 `FILE_ID_INFO`（4+16=20 字节）不一致，`VolumeSerial` 混入文件 ID 字节并读出 4 字节未初始化尾部；改为 `Pack=4` 正确偏移 + 4 字节填充（实测 API 拒绝 <24 字节缓冲）。新增 T57 回归：同文件身份稳定、异文件可区分、卷序列号 ≤32 位。
3. L2 强确认覆盖多父目录：此前仅校验第一个 L2 条目的父目录名；现在跨多个不同父目录时需逗号分隔全部输入（顺序不限）。
4. 安装器 `VersionInfoVersion` 由硬编码 1.0.0.0 改为跟随 `-Version` 参数。
5. `build-release.ps1` 自动生成 `SHA256SUMS.txt`（覆盖单文件 exe 与安装包），消除手工步骤。
6. 审查更正：此前报告的「暂停后取消 → 下次扫描挂起」为误报——状态机终态不允许任何转换，且 UI 每次扫描新建 `ScanService` 实例，脏状态路径不可达。
